# AL NOOR Loyalty — Presentation Build

This build consolidates the current customer, staff, and GM work into one clean PWA structure.

## Customer
- Email-only Magic Link login
- No customer password
- Registration
- Loyalty card + QR
- Points
- Rewards history
- Menu / Offers

## Staff
- Email + password login
- QR scan / manual token
- +1 Visit
- Reward redemption
- Transaction history with staff member when the RPC is available

## GM
- Dashboard
- Members
- Locations
- Reports
- Settings

The approved AL NOOR BAKERY & CAFE logo is used as the image asset without redesigning the logo itself.


## FINAL-3 verification
This package contains 36 real project files (directories are not counted). The local references, JavaScript syntax, critical page panels, QR flow guards and service-worker cache behavior were checked before packaging.

Important: a static package check cannot prove a live Supabase login/RPC result. The live project must still have the current publishable key and the required database functions/tables.
